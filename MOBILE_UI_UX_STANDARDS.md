## 1. Области нажатия (Touch Targets & Hitboxes)

### Стандарты платформ:
* **Apple Human Interface Guidelines (HIG)**: минимальный размер интерактивного элемента — **44 × 44 pt** (~9.5 мм).
* **Google Material Design 3 (M3)**: минимальный размер кликабельной зоны — **48 × 48 dp** (~10 мм).
* **WCAG 2.2 (Доступность)**: уровень AAA требует область нажатия не менее **44 × 44 px**.

### Почему это критично:
Подушечка пальца человека имеет физическое пятно контакта от 8 до 11 мм. Если кнопка или иконка имеет размер 24–32px без расширенной области клика, вероятность случайного промаха возрастает в 3–4 раза.

### Золотой CSS-паттерн «Невидимый хитбокс»:
Иконка остается визуально компактной (например, 24px или 38px), но зона клика расширяется до 44–48px через псевдоэлемент:
```css
.icon-button {
  position: relative;
  width: 38px;
  height: 38px;
}

.icon-button::after {
  content: '';
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  min-width: 44px;
  min-height: 44px;
  width: max(100%, 44px);
  height: max(100%, 44px);
  pointer-events: auto;
}
```

## 2. Безопасные зоны экрана (Safe Areas)

### Что такое Safe Area:
На современных смартфонах экран имеет закругленные углы, аппаратную «чёлку» (Notch), вырез **Dynamic Island** (iPhone) или полоску системных жестов снизу (**Home Indicator Bar** на iOS и жестовая навигация на Android).

### 1. Мета-тег Viewport:
Чтобы браузер позволил контенту заполнять весь экран от края до края, необходим параметр `viewport-fit=cover`:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />
```

### 2. Системные переменные CSS `env()`:
* `env(safe-area-inset-top)` — отступ под статус-бар, часы и Dynamic Island.
* `env(safe-area-inset-bottom)` — отступ над нижней полоской Home Indicator.
* `env(safe-area-inset-left)` / `env(safe-area-inset-right)` — отступы при альбомной ориентации.

### Пример адаптации хедера и контента:
```css
/* Верхний хедер с учетом челки/островка */
.mobile-header {
  min-height: calc(58px + env(safe-area-inset-top, 0px));
  height: calc(58px + env(safe-area-inset-top, 0px));
  padding-top: calc(8px + env(safe-area-inset-top, 0px));
  padding-bottom: 8px;
}

/* Нижняя часть приложения с учетом полоски жестов */
.app-main-content {
  padding-bottom: calc(24px + env(safe-area-inset-bottom, 0px));
}
```

## 3. Типографика и поля ввода (iOS Zoom Protection)

### Правило 16px для `<input>` на iOS:
Если на iPhone пользователь нажимает на поле ввода (`<input>`, `<select>`, `<textarea>`) с размером шрифта меньше **16px**, браузер Safari считает текст слишком мелким и **принудительно зумирует всю страницу**. Это ломает мобильную верстку.

### Решение:
```css
@media (max-width: 768px) {
  input:not([type="checkbox"]):not([type="radio"]),
  select,
  textarea {
    font-size: 16px !important;
  }
}
```

### Иерархия размеров шрифтов:
* **Крупный заголовок (Display/H1)**: 24–32px (жирный, 700–800)
* **Заголовок секции / карточки (H2/H3)**: 18–22px (600–700)
* **Основной текст (Body)**: 15–16px (регулярный, 400–500)
* **Вспомогательные подписи (Caption / Badge)**: 12–14px (500–600)

## 4. Модульная сетка и размеры (8pt Grid System)

И Apple HIG, и Google Material 3 используют сетку, кратную **4px и 8px**:
* **Отступы (Margins & Paddings)**: 4, 8, 12, 16, 20, 24, 32, 40, 48px.
* **Высота стандартных панелей**:
  * Верхний хедер (Top App Bar): **56–64px** (в нашем приложении: **58px** — идеальный баланс).
  * Основная кнопка действия (Primary Button): **52–56px**.
  * Поле ввода (Text Input): **48–54px**.
  * Нижняя панель навигации (Bottom Nav): **56–64px**.
* **Скругления углов (Border Radius)**:
  * Малые элементы (бейдж, тег): 6–8px.
  * Кнопки, инпуты: 12–16px.
  * Карточки, модальные окна: 16–24px.
  * Пилюли / округлые переключатели: 9999px.

## 5. Жесты, физика анимаций и тактильный отклик (Haptics)

### 1. Скорость анимаций (Micro-interactions):
* **Быстрый отклик на тап**: 100–180мс.
* **Свайп карточки / смена экрана**: 200–300мс.
* **Кривые плавности**: использовать `cubic-bezier(0.25, 1, 0.5, 1)` (пружинящая физика iOS) или `cubic-bezier(0.2, 0, 0, 1)` (Material 3 standard decelerate).

### 2. Тактильный отклик (Haptic Feedback):
Вибрация подтверждает действие пользователя на физическом уровне.
```javascript
export function triggerHaptic(type = 'light') {
  if (typeof navigator !== 'undefined' && navigator.vibrate) {
    try {
      if (type === 'light') navigator.vibrate(10);          // легкий клик/свайп
      else if (type === 'medium') navigator.vibrate(22);     // переключение тумблера
      else if (type === 'success') navigator.vibrate([12, 35, 18]); // победный аккорд
      else if (type === 'error') navigator.vibrate([30, 40, 30]);   // ошибка
    } catch (e) {}
  }
}
```

## 6. Состояния интерактивных элементов

### Обязательные состояния:
1. **Default**: Базовый вид.
2. **Hover**: Для мыши (на мобильных устройствах не должен зависать при тапе).
3. **Active / Pressed**: Мгновенный отклик при нажатии пальцем:
   ```css
   .primary-button:active {
     transform: scale(0.97);
     filter: brightness(0.95);
   }
   ```
4. **Disabled**: Полупрозрачность (`opacity: 0.4–0.5`), запрет кликов `pointer-events: none;`.

### Отключение системной серой подсветки тапа:
На мобильных браузерах WebKit по умолчанию добавляет серый прямоугольник при каждом тапе. Его отключают глобально:
```css
* {
  -webkit-tap-highlight-color: transparent;
}
```

## 7. Темная тема (Dark Mode Ergonomics)

1. **Не использовать чистый черный (`#000000`) для всех поверхностей**:
   * Фон базового слоя: глубокий сланцевый `#0f172a` или темно-серый `#121212`.
   * Карточки и всплывающие слои (Elevation): `#1e293b` или `#1e1e1e`.
2. **Смягчение контраста белого текста**:
   * Вместо `#ffffff` для основного текста использовать `#f8fafc` или `#e2e8f0` — это снижает усталость глаз в темноте.
3. **Цветовая гамма акцентов**:
   * Яркие дневные цвета (синий, зеленый, оранжевый) в темной теме слегка осветляются и делаются более пастельными, чтобы не «резать» глаза.

## 8. Итоговый чек-лист мобильного интерфейса

* [x] **Safe Area**: Мета-тег `viewport-fit=cover` и отступы `env(safe-area-inset-*)` на месте.
* [x] **Touch Targets**: Все кнопки и кликабельные иконки имеют область $\ge$ 44×44px.
* [x] **Поля ввода**: Размер шрифта инпутов $\ge$ 16px (нет авто-зума на iPhone).
* [x] **Tap Feedback**: Отключен `-webkit-tap-highlight-color: transparent`, настроен `:active` эффект.
* [x] **Тактильность**: Подключен `triggerHaptic` на ключевые действия и свайпы.
* [x] **Вертикальный баланс**: Хедер (58px) и кнопки (52–56px) согласованы по сетке.
* [x] **Быстродействие**: Анимации используют `transform` и `opacity` (аппаратное ускорение GPU).
