1. ОБЛАСТИ НАЖАТИЯ (TOUCH TARGETS & HITBOXES)
================================================================================

СТАНДАРТЫ ПЛАТФОРМ:
• Apple Human Interface Guidelines (HIG):
  Минимальный физический размер зоны тапа: 44 x 44 pt (~9.5 мм).
• Google Material Design 3 (M3):
  Минимальный размер кликабельной зоны: 48 x 48 dp (~10 мм).
• Международный стандарт доступности WCAG 2.2:
  Уровень AAA требует область нажатия не менее 44 x 44 px.

ПОЧЕМУ ЭТО КРИТИЧНО:
Подушечка пальца взрослого человека имеет физическое пятно контакта от 8 до 11 мм.
Если кнопка, стрелка или иконка имеет визуальный размер 20-32px без расширенного
хитбокса, вероятность случайного промаха возрастает в 3-4 раза.

ПАТТЕРН "НЕВИДИМЫЙ ХИТБОКС" (CSS):
Иконка остается визуально аккуратной и компактной (например, 24px), а область
нажатия расширяется до 44-48px с помощью прозрачного псевдоэлемента:

.icon-button {
  position: relative;
  width: 38px;
  height: 38px;
}

.icon-button::after {
  content: '';
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  min-width: 44px;
  min-height: 44px;
  width: max(100%, 44px);
  height: max(100%, 44px);
  pointer-events: auto;
}

================================================================================
2. БЕЗОПАСНЫЕ ЗОНЫ ЭКРАНА (SAFE AREAS & DYNAMIC ISLAND)
================================================================================

ЧТО ТАКОЕ SAFE AREA:
Современные смартфоны оснащены закругленными углами корпуса, аппаратными
вырезами под камеру (Notch, Dynamic Island на iPhone) и системными полосками
жестовой навигации (Home Indicator Bar на iOS / жест «Назад/Домой» на Android).

1. МЕТА-ТЕГ VIEWPORT:
Чтобы браузер позволил контенту заполнять экран до физических граней устройства,
обязателен параметр viewport-fit=cover:

<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />

2. СИСТЕМНЫЕ CSS-ПЕРЕМЕННЫЕ env():
• env(safe-area-inset-top)    — отступ под статус-бар, часы и Dynamic Island.
• env(safe-area-inset-bottom) — отступ над системной полоской Home Indicator.
• env(safe-area-inset-left)   — отступ слева в альбомной ориентации.
• env(safe-area-inset-right)  — отступ справа в альбомной ориентации.

ПРИМЕР АДАПТАЦИИ ХЕДЕРА И ОСНОВНОГО КОНТЕНТА:
/* Хедер с динамическим отступом под челку/островок */
.mobile-header {
  min-height: calc(58px + env(safe-area-inset-top, 0px));
  height: calc(58px + env(safe-area-inset-top, 0px));
  padding-top: calc(8px + env(safe-area-inset-top, 0px));
  padding-bottom: 8px;
}

/* Нижняя панель или футер с отступом под полоску жестов */
.app-main-content {
  padding-bottom: calc(24px + env(safe-area-inset-bottom, 0px));
}

3. ТИПОГРАФИКА И ПОЛЯ ВВОДА (IOS ZOOM PROTECTION)
================================================================================

ПРАВИЛО 16PX ДЛЯ <INPUT> НА IOS:
Если размер шрифта в поле ввода (<input>, <select>, <textarea>) меньше 16px,
браузер Safari на iPhone считает шрифт нечитаемым и принудительно масштабирует
(зумирует) всю страницу при фокусе, что ломает верстку.

РЕШЕНИЕ:
@media (max-width: 768px) {
  input:not([type="checkbox"]):not([type="radio"]),
  select,
  textarea {
    font-size: 16px !important;
  }
}

ИЕРАРХИЯ ШРИФТОВ ДЛЯ МОБИЛЬНЫХ ЭКРАНОВ:
• Крупный заголовок (Display / H1): 24-32px (жирность 700-800, line-height 1.25)
• Заголовок секции / карточки (H2/H3): 18-22px (жирность 600-700)
• Основной текст (Body): 15-16px (жирность 400-500, line-height 1.4-1.5)
• Вспомогательные подписи (Caption / Badge): 12-14px (жирность 500-600)

================================================================================
4. МОДУЛЬНАЯ СЕТКА И РАЗМЕРЫ (8PT GRID SYSTEM)
================================================================================

СЕТКА 4PX / 8PX:
Все ключевые размеры и отступы должны быть кратны 4 и 8:
• Отступы (Margins / Paddings): 4, 8, 12, 16, 20, 24, 32, 40, 48px.
• Высота стандартных компонентов:
  - Верхний хедер (Top App Bar): 56-64px (в нашем приложении: 58px — оптимум).
  - Главная кнопка действия (Primary Button): 52-56px.
  - Поле ввода (Text Input): 48-54px.
  - Нижняя панель навигации (Bottom Nav): 56-64px.
• Скругления углов (Border Radius):
  - Малые элементы (бейдж, тег): 6-8px.
  - Кнопки, поля ввода: 12-16px.
  - Карточки, модальные окна: 16-24px.
  - Пилюли и чипы: 9999px (полное скругление).

5. ЖЕСТЫ, ФИЗИКА АНИМАЦИЙ И ТАКТИЛЬНЫЙ ОТКЛИК (HAPTICS)
================================================================================

1. СКОРОСТЬ И ПЛАВНОСТЬ АНИМАЦИЙ (MICRO-INTERACTIONS):
• Быстрый отклик на нажатие (клик / тап): 100-180 мс.
• Смена экрана / свайп карточки: 200-300 мс.
• Кривые плавности (Easing):
  - iOS-пружина: cubic-bezier(0.25, 1, 0.5, 1)
  - Material 3 стандартное замедление: cubic-bezier(0.2, 0, 0, 1)

2. ТАКТИЛЬНЫЙ ОТКЛИК (HAPTIC FEEDBACK API):
Вибрация подтверждает действие пользователя на физическом уровне:

export function triggerHaptic(type = 'light') {
  if (typeof navigator !== 'undefined' && navigator.vibrate) {
    try {
      if (type === 'light') navigator.vibrate(10);                  // легкий клик/свайп
      else if (type === 'medium') navigator.vibrate(22);             // тумблер/переключатель
      else if (type === 'success') navigator.vibrate([12, 35, 18]); // победный аккорд/верно
      else if (type === 'error') navigator.vibrate([30, 40, 30]);   // ошибка
    } catch (e) {}
  }
}

6. СОСТОЯНИЯ ИНТЕРАКТИВНЫХ ЭЛЕМЕНТОВ
================================================================================

ОБЯЗАТЕЛЬНЫЕ СОСТОЯНИЯ КОМПОНЕНТОВ:
1. Default: Исходный вид кнопки или поля.
2. Hover: Только для десктопа (не должен "залипать" на мобильных при тапе).
3. Active / Pressed: Мгновенное тактильное сжатие при нажатии:
   .primary-button:active {
     transform: scale(0.97);
     filter: brightness(0.95);
   }
4. Disabled: Полупрозрачность (opacity: 0.4-0.5) + pointer-events: none.

ОТКЛЮЧЕНИЕ СЕРОЙ СИСТЕМНОЙ ПОДСВЕТКИ ТАПА НА SAFARI/CHROME:
* {
  -webkit-tap-highlight-color: transparent;
}

================================================================================
7. ЭРГОНОМИКА ТЕМНОЙ ТЕМЫ (DARK MODE ERGONOMICS)
================================================================================

1. НЕ ИСПОЛЬЗОВАТЬ ЧИСТЫЙ ЧЕРНЫЙ (#000000) ДЛЯ ВСЕХ ПОВЕРХНОСТЕЙ:
• Базовый фоновый слой: глубокий сланцевый #0f172a или темно-серый #121212.
• Карточки и модальные окна (Elevation 1-2): #1e293b или #1e1e1e.
• Внутренние контейнеры (Elevation 3): #334155 или #2d2d2d.

2. СМЯГЧЕНИЕ КОНТРАСТА ТЕКСТА:
Вместо ядовито-белого #ffffff использовать мягкие оттенки (#f8fafc или #e2e8f0),
чтобы снизить зрительное утомление в темноте.

3. ПАСТЕЛЬНЫЕ АКЦЕНТЫ:
Яркие дневные цвета (синий, зеленый, оранжевый) в темной теме слегка осветляются
и делаются более пастельными, избегая визуального "дребезга" контуров.
