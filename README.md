# My Duolingo

Современное веб-приложение для изучения английского языка, вдохновлённое Duolingo и адаптированное под персональное обучение.

## Цель проекта

Создать масштабируемое веб-приложение коммерческого уровня с использованием современных веб-технологий и Google Apps Script.

## Технологический стек

### Frontend

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- PWA
- SpeechSynthesis API

### Backend

- Google Apps Script
- Google Sheets
- REST API (JSON)

## Среда разработки

- Visual Studio Code
- Git
- GitHub
- Node.js
- clasp
