## 🎯 Цель проекта

Создать современное веб-приложение коммерческого уровня для изучения английского языка.

Основные принципы:

- модульная архитектура;
- разделение Frontend и Backend;
- масштабируемость;
- чистый и понятный код;
- профессиональная документация;
- поэтапная разработка.
