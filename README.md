# 🦉 English Trainer (My Duolingo)

> Современное, быстрое и удобное веб-приложение (PWA) для эффективного изучения английских слов по методике интервального повторения.

🔗 **Live Demo:** [https://sway-nick.github.io/my-duolingo/](https://sway-nick.github.io/my-duolingo/)

---

## 🚀 Основные возможности

### 1. 🗂️ 4 Режима интеллектуальной тренировки:
- **🗂️ Карточки (Cards):** Первичный отбор слов на день (с настраиваемым дневным лимитом: 10, 20, 30... слов) с разделением на «Учить» и «Знаю».
- **🎯 Квиз (Quiz):** Выбор правильного перевода из 4 вариантов. Звуковые эффекты верных ответов и 4-секундная пауза при ошибках для комфортного запоминания.
- **🧩 Пары (Pairs):** Интерактивное сопоставление 6 пар слов на скорость с плавной 3D-анимацией переворота карточек и звуком звонких монеток.
- **✍️ Ввод слова (Input Test):** Ввод правильного английского слова с клавиатуры по русскому переводу с системой закрепления (3 успешных ввода для полного выучивания).

### 2. 👥 Мультипользовательский режим и синхронизация:
- **Гостевой режим (Guest):** Мгновенный старт без регистрации с сохранением прогресса на устройстве.
- **Облачная авторизация:** Вход по Email/паролю с полной синхронизацией прогресса, настроек и избранного через Google Apps Script & Google Sheets.

### 3. 🎭 Персонализация и аватарки:
- Встроенная галерея из **16 уникальных векторных персонажей** (адаптированы, отцентрированы и масштабированы под единый стандарт).
- Возможность загрузки собственного фото с автоматическим кадрированием и сжатием.
- Синхронизация аватара в шапке и настройках профиля.

### 4. 🔊 Умная озвучка (SpeechSynthesis):
- Натуральные мужской (баритон) и женский голоса с приоритетом естественных движков.
- **Режим «Черепашка»:** автоматическое замедление произношения на 3-й клик подряд для разбора сложных звуков.
- Быстрый переключатель звука/тихого режима в Настройках.

### 5. 📖 Мгновенный Словарь и Избранное:
- Высокопроизводительный словарь (Batch Infinite Scroll + Event Delegation) с моментальным переключением вкладок без задержек при любом объёме базы.
- Удобный поиск с автозадержкой (debounce) и фильтрация по категориям.
- Раздел «Избранные слова» с возможностью запуска отдельной тренировки только по сложным словам.

### 6. 🎨 Интерфейс и Темы:
- Поддержка **Светлой** и **Тёмной** темы с мгновенным переключением.
- Полная адаптивность для мобильных телефонов, планшетов и ПК.

## 🛠️ Технологический стек

- **Frontend:** HTML5, Vanilla CSS3 (Custom Properties, Flexbox/Grid, 3D CSS Transforms), Vanilla JavaScript (ES6+ Modules), Web Audio API, Web Speech API.
- **Backend:** Google Apps Script (Serverless Endpoint), Google Sheets (Database).
- **Сборка и развёртывание:** Node.js sync script (`scripts/build.cjs`), GitHub Pages.

## 💻 Локальная разработка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/sway-nick/my-duolingo.git
   cd my-duolingo
   ```

2. Вносить изменения в исходные файлы папки `frontend/`.

3. Синхронизировать сборку в `docs/` и корень:
   ```bash
   node scripts/build.cjs
   ```

4. Открыть `frontend/index.html` или `docs/index.html` в браузере (или через Live Server).
