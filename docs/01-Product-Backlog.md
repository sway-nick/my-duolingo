# Product Backlog

## MVP

### Epic 1. Content

#### Feature: Vocabulary

- As a user, I want to browse my vocabulary list.
- As a user, I want to search words.
- As a user, I want to filter words by category.
- As a user, I want to mark words as favorite.
- As a user, I want to edit my vocabulary.

#### Feature: Irregular Verbs

- As a user, I want to browse irregular verbs.
- As a user, I want to study verbs by groups.
- As a user, I want to use mnemonic stories.
- As a user, I want to search irregular verbs.

#### Feature: Import from Google Sheets

- As an administrator, I want to import vocabulary from Google Sheets.
- As an administrator, I want to validate imported data.
- As an administrator, I want to update existing words.

---

### Epic 2. Learning

#### Feature: Flashcards

- As a user, I want to study words using flashcards.
- As a user, I want to flip a card.
- As a user, I want to hear pronunciation.

#### Feature: Translation

- As a user, I want to translate from English to Russian.
- As a user, I want to translate from Russian to English.

#### Feature: Listening

- As a user, I want to listen to word pronunciation.
- As a user, I want to repeat pronunciation.

#### Feature: Answer Checking

- As a user, I want to know whether my answer is correct.
- As a user, I want to see the correct answer after a mistake.

---

### Epic 3. Progress

#### Feature: Statistics

- As a user, I want to see how many words I have learned.
- As a user, I want to see my learning progress.

#### Feature: Correct Answers

- As a user, I want to see my accuracy.

#### Feature: Learning History

- As a user, I want to see my previous training sessions.

---

### Epic 4. Administration

#### Feature: Import Data

- As an administrator, I want to import learning content.

#### Feature: Export Data

- As an administrator, I want to export learning content.

#### Feature: Diagnostics

- As an administrator, I want to check system health.

---
